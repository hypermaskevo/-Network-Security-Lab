# -Network-Security-Lab
This project is a lab exercise focused on building a network topology in Cisco Packet Tracer. The lab simulates a corporate network with two branch offices, servers, firewalls, and a potential threat actor (attacker). It is designed to help understand routing, segmentation, and basic network security principles.
![image](https://github.com/user-attachments/assets/f10c69ed-a744-462a-a90e-75e08f345e5f)
🧪 Lab Instructions
Recreate the network topology shown at 16:40 in the Day 1 video.

Use the following devices:

2x Cisco 2911 Routers

2x Cisco 2960 Switches

2x Cisco ASA 5505 Firewalls

2x PCs

2x Servers

1x Laptop (used as the "Attacker")

Connect devices using Packet Tracer’s "Automatically Choose Connection Type" function.

🌐 Network Layout
New York Branch

PC1, PC2, Switch (SW1), Router (R1), Firewall (FW1)

Internet Zone

Attacker (connected between FW1 and FW2)

Tokyo Branch

Switch (SW2), Servers (SRV1, SRV2), Router (R2), Firewall (FW2)

🎯 Objectives
Understand the structure of a basic enterprise network.

Implement firewall security using Cisco ASA.

Simulate an external attacker and test access control mechanisms.
